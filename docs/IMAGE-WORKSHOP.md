# 小羊图片工坊 · 格式转换

本地 Windows 图片工具。0.2 新增照片库与 Sony RAW 编辑，使用方法和调研依据见 [RAW 工作流](PHOTO-WORKFLOW.md)。本文说明保留的“格式转换”页签。入口为工作箱应用卡片 `xiaoyang-images`，或 `desktop-dev/小羊图片工坊.exe`。移动时保留整个开发目录；当前不制作安装包。

## 使用

1. 使用工作箱账号登录，添加或拖入图片。
2. 选择输出格式；JPG、AVIF 和有损 WebP 可调整质量，WebP 可选择无损。
3. JPG 不支持透明，使用“透明区域填充”选择底色。
4. 通过系统文件夹选择器选择输出目录，点击“开始转换”。完成后可打开输出文件夹、定位文件。

| 输入 | 输出 |
| --- | --- |
| PNG、JPG/JPEG、WebP、AVIF、TIF/TIFF、静态 GIF | PNG、JPG、WebP、AVIF、TIFF |

格式转换页只接受静态、单页图片，RAW 请使用照片库；动图、多页 TIFF、HEIC、SVG、PDF 不在此页支持范围。最多 50 张、单张 25 MiB、单批 250 MiB、单张 4000 万像素。超限或损坏文件会显示错误；批处理中单张失败不阻断其他图片。

转换保留像素尺寸，按 EXIF 方向实际旋转，输出标准 sRGB 图片。输出移除 EXIF/GPS 等元数据；不作为 RAW、HDR、16 位母版归档流程。PNG/TIFF 使用无损压缩，质量滑块仅用于有损编码。界面预览是原图缩略图，输出结果显示名称和实际体积。

## 文件与清理

- 原图不改动。同名输出自动追加 ` (2)`、` (3)`，独占创建，不能覆盖已有文件。
- 默认导出到 `%LOCALAPPDATA%\XiaoyangWorkbox\图片工坊导出`；选定目录在当前窗口会话内保留，清空列表不重置目录。
- 临时输入副本、预览和编码文件位于数据目录的 `image-workshop-temp/session-进程号-随机串`。清空、移除、注销和正常关闭会清理；下次启动回收已终止服务留下的专用目录。不会清理成功导出的文件或用户源文件。
- 停止转换会停止队列；当前编码有 20 秒上限，结束后不发布被取消的结果。已经完成的输出保留。关闭图片工坊时等待服务清理，极端情况下由下次启动回收残留。
- 不调用外网服务；预览和转换接口使用 `no-store`。底层 sharp 缓存关闭，批次逐张处理、原生线程数限制为 2。

## 平台接入

遵循 [工作箱规范](STANDARDS.md)：独立登录边界、共享账号与主题、默认 1200×860／最小 1120×720、浅色／深色／跟随系统、蓝色按钮和紧凑圆角面板。复用系统 WebView2、现有 Node 和账号库，不捆绑第二套浏览器或解释器。每个 Windows 用户单实例；关闭工具不结束其他应用。

界面 `src/ImagesPanel.tsx` 与转换引擎 `server/image-engine.ts` 均按需加载。共享结构位于 `shared/images.ts`，认证与队列位于 `server/images.ts`。以后可以沿这些边界增加裁切、缩放等功能，当前没有未实现的按钮。

私有回环服务要求桌面令牌和登录会话。前端只提交图片内容、已导入 ID 和受校验的转换设置，不能指定输入路径或命令。输出路径只能由原生文件夹选择器提交，另需仅原生宿主持有的能力令牌；文件定位从当前用户任务结果解析，不接受前端路径。第三方组件与版本见 [第三方说明](THIRD-PARTY.md)。

## 开发与验证

```powershell
npm run build
npm run images:host
node scripts/update-app.mjs
npm test
npx tsx tests/images-ui.ts
node tests/bundled-smoke.mjs
```

增量构建只生成图片工坊宿主，更新脚本先备份共享资源，并复制 sharp 的 Windows x64 本地依赖与许可证。完整 `npm run desktop:build` 同样包含图片工坊。旧工作箱需从托盘退出后重新打开，才能读取新入口。
