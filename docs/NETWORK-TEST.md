# 小羊网络测试

## 测试目标

Ping、DNS、TCP 和路由追踪支持粘贴域名、IP、完整 HTTP(S) 网址或省略协议的网址，例如 `yellowdogsleague.online/versus/`、`https://yellowdogsleague.online/versus/`。开始后输入框显示实际探测的主机；路径、查询参数和片段不参与探测，也不保存到报告。修改后的目标在切换测试页时保留，查看测速节点历史不会覆盖它。

TCP 自动采用网址中显式指定的端口；完整 HTTPS / HTTP 网址未写端口时分别使用 443 / 80。仅输入域名或 IP 时使用端口输入框的值。IPv4、IPv6 和国际化域名均可输入；带账号密码的网址、其他协议、无效端口和命令文本会被拒绝。

这些项目检查主机连通性，不测具体页面加载时间。Ping 超时可能是 ICMP 被禁用，可继续使用 TCP 443 检查 HTTPS 端口。

## 测速与节点

默认节点为南京航空航天大学（江苏南京、教育网），支持下载和上传；可切换 Cloudflare 全球边缘节点。最近选择保存在本机。节点由服务端固定登记，客户端只能传节点 ID，不能提交任意上传地址。

当前为固定时间测速：**先下载 15 秒，再上传 15 秒**，正常完成约 30 秒。每阶段持续循环传输，15 秒到时主动终止未完成的请求，清理下载连接后才进入上传；不会同时测两个方向。每个方向最多两条连接，单请求数据块是传输实现细节，不决定阶段结束条件。进度按时间计算，不再提供“快速／标准”流量模式；流量随实际网速变化。

15 秒包含该方向建立连接的时间。连接最长等待 6 秒；连续 10 秒无数据视为失败；单请求另有 45 秒兜底，但会被更短的阶段计时中断。连接失败、超时或用户停止不会伪装成完成；保留已取得的采样、最高值和已完成方向的平均结果。换节点开始新的报告，不混合节点数据。旧客户端传来的 quick／standard 参数仅为兼容读取，新任务仍固定 15＋15 秒。

测速采用 Node 直接 HTTPS 请求，不读取 Windows 的 HTTP 代理设置；VPN、TUN 或路由器仍可能改变路径。结果代表本机至所选节点的 HTTP 吞吐量，并非运营商签约带宽或完整线路容量认证。跨运营商、教育网互联和节点负载均可能影响结果。

下载、上传分为独立两栏，下载蓝色、上传紫色，各自有从 0 到 15 秒的横轴、实时／平均速度、最高值和阶段状态。每秒按真实字节增量计算一个 Mbps 采样点，曲线上不常驻显示数值，悬停可读取实际采样的时间和速度。曲线采用保形三次插值平滑连接采样点，避免额外过冲；平均值、最高值及报告仍使用原始数据。最高值是采样区间速度的最大值；平均值为本阶段累计字节 ÷ 15 秒，不拿最高值代替平均值。计时只允许真实采样，零点为绘图起点，不参与最高值计算。

下载按收到的正文计数；上传按缓冲区交给套接字的进度估算，可能受系统发送缓冲影响，上传栏明确标为“本机发送估算”。它不代表服务器确认收到的吞吐量。未完成方向不提供最终平均值。历史与 JSON 导出保留方向内时间、方向平均值和最高值、实际字节数、节点、状态和采样；旧流量制记录依原始采样时长回看，没有采样时明确提示。

## 本地缓存与清理

测速数据流不写入文件，也不经过浏览器下载或 WebView2 的内容缓存：Node HTTPS 流只累计字节，上传重复使用至多 64 KiB 的随机内存块。测速请求和本地 API 响应均使用 `Cache-Control: no-store`；请求还包含随机参数，避免代理复用旧响应。

每个阶段单独管理连接池。正常结束、停止、异常和退出均终止请求、关闭连接池、取消定时器并解除中止监听，传输缓冲随后由运行时回收，不留下需删除的测速下载文件。保留的只有账号内最近 50 份轻量统计／曲线报告；用户主动导出的 JSON 仍按用户选择的位置保存。

## 网络信息

打开工具只读取本地信息，点击“检测网络信息”才查询公网，不与测速同时执行。国内来源为 IPIP；无法获得完整双出口结果时尝试 ipapi.co。两次出口对比使用同一来源，分别通过 Windows 系统代理规则和禁用应用层 HTTP 代理请求，显示时间、服务来源和错误。连续 10 秒内复用结果，并限制请求频率。

- 公网 IP、IPv4 / IPv6 类型、IP 估算归属地、运营商或组织；来源有提供时显示 ASN 和时区。
- 系统手动代理、PAC 配置、实际查询采用的代理端点。端点剔除账号、密码和 URL 查询参数；PAC 仅显示是否配置。
- 本地网卡 IPv4 / IPv6、网关、DNS 和物理链路标称速率。疑似 VPN / TUN 网卡仅作线索，不据此宣称流量一定经过 VPN；虚拟网卡不显示无意义的标称百 Gbps 数值。

“系统代理已用于查询”表示该次请求确实选用了代理，并收到有效 IP 响应。两个出口 IP 相同，也不代表未使用代理；代理软件可能对国内站点采用直连规则。未检测到系统 HTTP 代理不等于排除所有 VPN、透明代理或路由器代理。

IP 定位无法给出实际居住地址。“直连请求出口”也不承诺绕过 VPN / TUN 或恢复被代理隐藏的运营商 IP。不给出未经证实的“真实住址”或“绝对无代理”标签。

## 早前节点连通性验证 · 2026-10-03

- 南航与 Cloudflare 各通过 1 MiB 下载和 1 MiB 上传请求验证。南航在隔离界面完成一次完整快速测试：下载 106.81 Mbps、上传 60.86 Mbps。这是当时本机到节点的样本，不作为日后速度保证。
- 实际验证 IPIP 国内查询、系统代理与直连出口、代理端点、本地网卡／DNS；观察到两个公网 IP 相同但系统查询使用本地代理的情况，正确保留“代理已使用”结论。
- 界面验证节点切换、主动停止、历史曲线读取、浅色／深色显示。独立测试数据库不修改正式测试历史。
- 自动化覆盖实时采样、上传／下载字节、取消、无数据超时、无效响应、残缺下载、IP 格式校验、代理分类、鉴权、节点 ID 白名单和历史存储。
- 未模拟全部运营商、全部 PAC 脚本或多个 VPN 产品；第三方节点和 IP 服务的长期可用性不作保证。

南京大学在本机访问时返回 Anubis 验证页面，中科大官方页面也要求 PoW 验证，故没有作为直接测速节点加入；不绕过站点验证或把验证页面字节计作测速。当前没有接入需要商用授权的 SpeedTest.cn SDK。

## 接口依据

- [南航官方测速页面](https://speed.nuaa.edu.cn/)及其 `speedtest_worker.js`：`backend/garbage.php` 下载、`backend/empty.php` 上传。
- [LibreSpeed 官方项目](https://github.com/librespeed/speedtest)：兼容端点协议说明，本次未复制项目代码或额外捆绑测速软件。
- [Cloudflare 测速项目](https://github.com/cloudflare/speedtest)：`__down` / `__up`。
- [IPIP 当前 IP 服务](https://myip.ipip.net/)、[ipapi.co 文档](https://ipapi.co/api/)：公网出口及估算归属地。
- [Microsoft GetSystemWebProxy](https://learn.microsoft.com/en-us/dotnet/api/system.net.webrequest.getsystemwebproxy)：读取当前 Windows 用户的系统代理规则。宿主仍使用现有 .NET Framework 4.8。
