# 本地文字识别

截图管理工具栏和纯文字右键菜单提供「文字识别」；格式转换页识别当前选中预览对应的原图；照片库识别当前显影预览（包括 RAW 的当前旋转／裁切／调整结果）。照片预览比全尺寸原片小，微小文字可先局部裁切或导出大图再识别。

支持简体中文、英文、混合语言，以及自动版面、单一文本块、零散文字。结果可编辑、复制。关闭弹窗或停止时取消任务；注销／服务关闭也释放任务。没有上传服务、在线识别、训练程序、系统安装器或常驻 OCR 进程。

使用 Tesseract 5.5.3 官方 Windows CLI 和固定提交 tessdata_fast 模型。只接收鉴权后图片字节，不接收文件系统路径或网址；最多 50 MiB、4000 万像素、静态单页。临时标准化到最长 4000 px、白底、灰度 PNG，最多两个 OpenMP 线程。图像转换限时 15 秒，识别进程限时 30 秒。结果仅保存在当前会话内存。

完成、失败、停止、注销、正常关闭都清除临时 PNG；异常退出后的 session-PID 目录仅在确认所属进程不存在后回收。不会删除截图、照片原片、导出文件或照片库缩略图。

`scripts/ocr-runtime.mjs` 仅复制 tesseract.exe 的 PE 依赖闭包与三个模型，不复制训练器、安装器和卸载器。可通过 `scripts/prepare-integrations.ps1` 下载、校验并解压到 `vendor/Tesseract-5.5.3`；已存在但哈希不同的固定组件会重新下载。固定版本与模型哈希保存在交付组件 `version.json`，构建时校验官方原始安装包哈希。解压过程未执行安装程序。许可证见 [第三方组件](THIRD-PARTY.md)。
