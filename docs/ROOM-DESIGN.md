# 小羊房间设计

2026-10-03 · 首版为本地二维编辑器，统一使用毫米。入口为工作箱应用卡片，或 `desktop-dev/小羊房间设计.exe`；共用工作箱账号、主题和本机数据目录。窗口默认 1200×860，最小 1120×720。

## 房间与家具

- 新建方案为没有预设边界的空白画布，可自由平移、缩放；自定义方案保留原轮廓。旧版未命名、无家具且未改动的 4000×3000 初始矩形在读取时移除，其顶点保留在方案中，可通过「快速矩形 → 恢复旧版边界」找回；用户画好的线段保留。新建及新版明确创建的矩形不会被此兼容处理清除。画布视野不限定房间大小，坐标保存范围仍为 ±50000 mm。
- 在「画房间」中点击起点、移动鼠标确定方向，按 **Tab** 输入长度（mm），按 **Enter** 落下这一段并继续绘制。输入长度不再经过网格取整或端点修正；小数长度也能保持。未输入时可直接点击落点。
- 动态输入框为独立 HTML 浮层，固定 **128×36 CSS px**、数值字号 **13 px**，只显示数值和 mm。画布缩放只改变定位，不缩放控件；Windows DPI／系统显示缩放仍按正常无障碍规则生效。
- 默认正交，**F8** 切换；关闭后可沿任意鼠标方向绘制斜墙。端点、中点吸附优先于正交与网格，吸附点有绿色形状及文字；附近顶点可提供水平／垂直对齐辅助线。**F3** 切换对象吸附，**F9** 切换 50 mm 网格，绘图时 **Alt** 暂停对象和网格吸附。
- 点击起点或按 **C**／「闭合」完成房间。**Esc / Enter**／「结束本段」结束当前线串，已确认线段转为独立对象，丢弃未确认的预览段或孤立起点，并继续等待新起点；下一次点击可以在任意位置开始，无需重选工具，也不自动连接上一串的末端。移除「继续画线」暂停状态。**Backspace / U** 只撤回当前线串末点；Ctrl+Z / Y 撤销重做不会重新激活已结束的线串。切换选择／平移也会结束当前线串。
- 自交、折返、墙边短于 100 mm、闭合面积小于 0.25 m² 会被拒绝。重画已有房间时，原轮廓保持到新轮廓成功闭合；线段单独保存。分次画线时，实际落下的线段与已有线串在无歧义的端点连接后，形成有效闭环才生成房间；不会补出未绘制的墙。
- 选择模式可拖动墙角改变轮廓；一次拖动计一步撤销，非法轮廓在松手时回滚。选中墙边可直接输入墙长或终点坐标；修改墙长固定起点及方向、移动终点，相邻墙会随之变化。独立线段同样支持端点拖动、长度／终点属性和 Delete 删除；删除闭合房间的一条墙会把其余墙转为开放线串，不补出替代墙。Esc 撤销当前拖动或未提交的属性数字。墙边标注为室内净尺寸；层高、墙厚为三维预留。
- 「快速矩形」作为可选快捷工具，输入宽、深后创建或替换轮廓。宽深为本次生成参数；现有轮廓通过墙角或墙边属性调整。
- 基础模板包括书桌、书架、椅子。从家具库拖入画布；选中后调整名称、长、深、高、坐标和角度。
- 「保存为家具模块」创建一份独立模板，保留家具种类、名称、三维尺寸和朝向。之后在「我的模块」中拖入任意方案。已摆放的实例和保存的模块互不联动，改一件不会改其他家具。
- 默认开启 50 mm 网格吸附及墙边／家具包围盒对齐。墙边按旋转后的真实家具轮廓计算，可吸附斜墙和墙角；拖动时按 Alt 暂停边缘吸附，网格开关独立控制。
- 布局检查按二维占地提示越界和重叠，边缘相接允许。它不包含门窗开启、走道净宽、人体工学或结构承重评估。

## 旋转

- 选中家具后拖动圆形旋转柄，可自由旋转。点击空白处／「选择」，可操作房间旋转柄。右侧也可输入精确角度，精度 0.1°；输入 -360°～360°，保存时归一化到 0°～小于 360°。
- 鼠标旋转时，在 0°、90°、180°、270°附近 5°内自动吸附。工具栏「角度吸附」可关闭，Alt 临时跳过。直接输入的角度始终按精确值处理，不强制吸附。
- 家具围绕自身中心旋转，房间围绕平面面积重心旋转。默认「家具随房间旋转」开启，保持家具与墙的相对位置；关闭后只转房间轮廓。尺寸、墙长和面积保持不变。
- R 顺时针旋转 90°，Shift+R 逆时针；选中家具时作用于家具，否则作用于房间。旋转柄获得键盘焦点后，左右键微调 1°，Shift+左右键调整 15°。
- 一次拖动或旋转计为一步撤销。Ctrl+Z 撤销，Ctrl+Y／Ctrl+Shift+Z 重做。方向键移动家具 10 mm，Shift+方向键移动 100 mm；Ctrl+D 复制，Delete 删除。
- 滚轮以鼠标位置缩放，中键／空格拖动画布；「平移」只移动视图，不修改房间坐标。缩放控件位于底部状态栏，避免遮挡墙端点；坐标转换使用 SVG 实际屏幕矩阵，适应面板尺寸变化。展开绘图工具栏不会重新适应画布；只有打开方案或主动点击「适应画布」才重新居中（快速矩形创建后也会适应轮廓）。

## 保存与数据

- 编辑后延迟 650 ms 自动保存；Ctrl+S／保存按钮立即保存。新建、切换方案前先保存。已落下的开放线段也会保存，重开后作为独立对象；重新画线从新起点开始。正常关闭房间设计窗口会等待当前方案保存；正在拖动时需先结束或取消。尚未确认的动态输入只是预览，不作为墙边保存。
- 方案和模块存入 `%LOCALAPPDATA%\XiaoyangWorkbox\workbox.sqlite`，按账号隔离。关闭所有共用数据库的工作箱工具后再复制数据目录备份。
- 可导出 `.room.json`；导入时验证格式、版本和单位，并生成新的方案 ID。原生保存对话框让用户选址，导出文本由现有桌面桥处理。
- 每账号最多 100 个方案、100 个家具模块；每方案的房间边界最多 64 个顶点、开放线串最多 64 组（每组最多 64 个点）、150 件家具，导入上限 256 KB。当前没有方案／模块库的删除、批量管理或云同步入口。
- 方案使用修订号避免不同窗口相互覆盖。兼容没有 `room.rotation` 的方案，按 0°读取；`room.paths` 保存结束后的开放线串，`room.draft` 保存当前线串已确认的点，旧版草稿读取时转为独立线串。`room.editorVersion: 2` 区分新版主动创建的轮廓；`room.legacyBoundary` 保留被移除的旧版初始边界。`room.vertices` 可为空，非空时必须是有效闭合轮廓。只有已闭合轮廓会传入未来三维的地面／墙体，开放草稿不生成虚假封闭房间。

交互参考 Autodesk 官方的 [动态输入](https://www.autodesk.com/learn/ondemand/curated/drawing-with-accuracy-in-autocad/52fjcj6oM0b8aTyKMX6YBH) 与 [对象捕捉](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-LT/files/GUID-50383F73-4F23-4F70-B4FC-52D5748D80AF.htm)，并参考 [LINE 命令与结束／撤回／闭合](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-Core/files/GUID-57CDDB6C-B12B-46CE-B9C5-22EFC17258FF.htm)。按本项目用户要求，Esc 后保持画线工具待选新起点；这不是完整复刻 AutoCAD 的命令状态机，也没有完整 CAD 命令行或图纸格式支持。

## 三维与模型接入契约

`shared/room.ts` 是唯一几何与数据契约：

- `RoomPlan`：毫米、房间顶点、层高、墙厚、家具尺寸和角度。二维 x 向右、y 向下，角度为顺时针。房间顶点已经是世界坐标，`room.rotation` 为编辑朝向记录，渲染器不能对顶点重复施加旋转。
- `RoomScene`／`toRoomScene()`：二维 x/y 映射为三维 x/z；对象尺寸为 `[宽, 高, 深]`，位置为包围盒中心 `[x, 高/2, y]`，绕 Y 轴旋转为负弧度。可沿墙线挤出层高与墙厚。
- `RoomRenderer3D`：`mount`、`update`、`dispose`；后续三维渲染器按需加载，二维入口不预加载三维引擎。
- `FurnitureModelAsset`：稳定资源 ID、来源、作者、许可证、相对资源路径、原始毫米尺寸、底面中心原点、缩放策略。目标分发格式为 GLB；这是本项目的转换目标，不代表各资源站都提供 GLB。
- 家具实例和模块可保存 `modelAssetId`。当前只保留引用字段，不加载任意 URL 或本机路径，不提供模型导入器。底面中心模型需由渲染器偏移到场景的包围盒中心契约，避免悬空或重复加高度。

| 资源 | 官方信息 | 适配建议 |

| [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit) | 3D 家具资源包，140 个文件，CC0 | 首选评估统一的基础家具外观；逐件核对几何、比例和格式，再转换为应用资产 |

| [Poly Haven 家具](https://polyhaven.com/models/furniture) | [资产采用 CC0](https://polyhaven.com/license)，允许修改和随产品分发 | 适合后续写实外观；按需下载，先测模型与贴图体积再决定分发规格 |

上述是可修改的开放模型资产，不是现成的参数化家具编辑器。软件需要将「真实尺寸」与「模型外观」分开：尺寸来自家具模块；模型加载时统一轴向、单位和原点并校准包围盒。书桌、书架优先分离桌面／板材／支腿，调整宽深高时改变组件位置与板长，保留合理板厚和腿粗，避免直接整体拉伸造成失真。椅子可先采用范围受限的整体尺寸适配，后续再细分组件。

建议下一阶段先挑选三件代表家具做离线适配样例，验证正面朝向、毫米尺寸、旋转、材质、包围盒与二维占地一致；通过后再扩充模型库。保留来源及许可证清单，即使 CC0 不强制署名也能追溯。

若未来调用 Poly Haven 在线服务，须单独遵循其 [API 条款](https://github.com/Poly-Haven/Public-API/blob/master/ToS.md)；模型资产许可不等同于网站／API 的使用规则。当前不接在线 API，也不自动抓取资源。
