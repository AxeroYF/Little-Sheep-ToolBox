# 小羊工作箱接入与界面规范 0.2

本文件适用于本地 Windows 开发版，更新初版规范中的桌面形态、账号入口和视觉约定。用户当前要求优先于历史规范。

## 应用形态

交付入口必须为可直接打开的 exe。开发版允许程序目录及依赖文件，不要求制作安装包。不得要求普通使用者先启动服务或打开浏览器。工具独立启动、独立退出，关闭工作箱不得结束黄狗风云等外部应用。

当前采用 WinForms + 系统 WebView2，复用 React 界面。界面文件随程序交付，不依赖远程网页。宿主启动仅监听回环地址的随机端口服务，并为请求注入每次启动随机生成的私有令牌；未携带令牌的其他浏览器或进程请求被拒绝。退出时优先关闭服务并取消测试，探测组件监视父进程退出。

## 登录边界

未登录时只显示登录表单和外观切换，禁止展示应用列表、收藏、最近使用或测试记录。登录成功后才挂载工具页面并请求这些数据。退出或收到会话失效响应时，清空当前界面数据并返回登录页；服务端必须独立验证所有工具、启动、偏好及报告接口。

注册入口与接口关闭，默认账号为「小羊」，初始密码使用用户指定值。只在账号不存在时初始化，不能在重启时覆盖密码。本机账号与未来云端账号必须明确区分。密码不能写入日志、配置、前端存储或数据库明文字段。

## 视觉与文案

- 浅色、深色、跟随系统共用同一套组件；用户主题按账号保存。
- 主色为蓝色 `#0675F9`，深色主色 `#1483FF`。面板使用细边框和 12–16 px 圆角；状态颜色必须配文字。
- Windows 桌面以紧凑侧栏、双列应用卡片、清晰主操作为基准。最小窗口 900×660；低高度允许纵向滚动。
- 独立工具窗口（小羊网络测试、小羊象棋、小羊房间设计、小羊图片工坊、小羊电脑信息、小羊视频播放器）默认 1200×860，最小 1120×720，居中打开并采用 DPI 缩放。工作箱主窗口保留 900×660 最小尺寸。工具共用系统字体、蓝色主色、细边框、14 px 面板圆角与 8–10 px 按钮圆角；内容布局按实际功能组织。
- 登录页独立居中，不能作为覆盖在应用列表上的弹窗。
- 去除欢迎语、宣传语、装饰性介绍和重复说明。只保留功能名称、必要输入提示、实际状态、单位及操作。
- 按钮必须真的执行功能；尚未实现的安装、同步、更新能力不放可点击假入口。
- 未测数据用“—”；失败、超时、停止、完成必须区分。不能用 0 代表缺失值。
- 输入要有标签；图标按钮提供可访问名称；键盘焦点可见。不得仅用颜色表达结果。

## 接入与权限

外部工具配置包含稳定 ID、名称、类别、平台、版本、固定 exe 位置及参数。运行时从登记 ID 查找启动信息，使用 `shell:false`；前端不得提交命令、覆盖路径或参数。清单有版本号，路径缺失必须有明确状态。`lifecycle.detection` 可选 `process`（默认，后台常驻工具）或 `window`（黄狗风云等有隐藏启动器的窗口应用）；窗口模式必须保留最小化运行状态，不能把隐藏辅助进程计为打开的应用。

黄狗风云只增加启动入口，不注入代码、不读写存档、不接管其账号。首次接入不推测其版本或运行状态；“已就绪”只表示启动文件存在，“启动请求成功”不等于游戏已加载完成。

小羊象棋登记为 `xiaoyang-chess`，由原棋类项目生成独立 exe；保留中国象棋、国际象棋、AI 与教程。工作箱在启动时传入已保存的 `--theme=light|dark|system`，不能接受前端自定义启动参数。单独打开时保留象棋自身主题；已有窗口按单实例规则激活，不中断棋局。象棋自行关闭引擎进程，关闭工作箱不结束棋局。

象棋界面采用 WebView2 固定虚拟域名保存主题和学习进度，通过限定消息桥接访问本机引擎；随机端口引擎服务要求私有令牌。原浏览器进度不自动迁移。独立程序目录保留运行时、AI 引擎、许可证与源码来源信息。

安装适配契约保留，当前安装能力为 false。未来 Windows 安装器和 Android 入口需要独立适配与验收，不能在未实现时声明支持。

## 轻量与资源

优先复用系统 WebView2，避免另外内置 Chromium。原生探测使用系统能力，不捆绑 Python、完整 .NET SDK 或其他网络测试软件。工具页不自动测速，不轮询无关服务。测试并发有上限；超时、取消和关闭必须释放套接字及探测子进程。

工作箱、网络测试、房间设计、图片工坊、电脑信息和视频播放器六个 exe 共用运行时、配置和界面资源；象棋开发目录自带其运行时与引擎。每种窗口每 Windows 用户最多运行一个实例。ShareX 另含其便携运行时和许可证／对应源码，目录体积不能继续沿用未接入前的 87 MiB。后续性能优化应先测量冷启动、空闲 CPU、总进程内存和 WebView 缓存，不以页面脚本大小替代这些指标。

## 视频播放器约定

小羊视频播放器沿用独立工具窗口尺寸、主题与登录边界，使用官方 LibVLC x64 动态组件，按需加载原生解码器。播放源只能来自用户选择的文件、明确输入的网络地址或已连接服务器；不加载网页传入的任意脚本／VLC 参数。服务器密码不持久保存，令牌和续播记录按账号本机加密。截图进入统一图库，播放和截帧临时资源在停止／退出时回收。应用关闭必须释放播放器并尝试同步进度。详见 [视频播放器](VIDEO-PLAYER.md)。

## 电脑信息约定

应用首页只复用一个开始按钮管理运行：运行中悬停显示「结束运行」。必须用实际进程和完整路径验证，正常退出保留保存逻辑，不强杀、不接管同名的其他程序。见 [应用运行管理](APP-LIFECYCLE.md)。

性能采集只读，不安装内核驱动或修改硬件设置。按需启动唯一采集器，隐藏全部显示界面后停止采样；注销、退出和父进程失效时回收。未知或不支持的指标保持缺失，不伪造温度、FPS 或零占用。只保留内存中的短期曲线，不无限写入历史。

逻辑处理器以 Windows group/index 区分；各物理设备保留独立身份。功率估算与传感器读数必须明确分开，不把负载百分比当实测瓦数；公开模型参数及范围，不把封装和子域功耗重复相加。LHM 传感器后台独立读取，慢设备不阻断系统基本采样。

悬浮窗提供可拖动小窗与鼠标穿透简洁模式，均不抢焦点；设置中提供位置、不透明度和关闭到托盘。自定义热键沿用先注册候选、再持久化、失败回滚的规则。简洁叠加不向游戏注入。详细采样口径及范围见 [电脑信息](COMPUTER-INFO.md)。

## 图片工坊约定

OCR 使用本地固定版本组件，仅处理已选择图片；原片只读，识别临时文件随任务结束回收。识别语言／版面可选，支持编辑复制和取消。照片库识别预览需明确标示，不能暗示全分辨率 OCR。见 [文字识别](OCR.md)。

先实现静态图片的本地批量格式转换；首版按需加载 sharp 原生引擎，不捆绑其他完整图片软件。输入文件、格式、像素与批次大小都需要验证，不能把动图或多页图片静默截成第一帧。逐张处理，支持取消、逐项结果和错误继续；JPG 透明填充必须明确可选。

原图不修改，同名文件独占创建并自动编号。临时输入、缩略图和编码中间文件在清空、注销、正常关闭时清理，异常退出遗留在下次启动回收；不能将用户导出文件当缓存删除。原生文件夹选择和文件定位使用独立能力校验，前端不能传入任意路径或命令。预览标明原图，压缩质量和无损选项不得宣称无损保留全部元数据。详见 [图片工坊](IMAGE-WORKSHOP.md)。

照片库的缩略图、评级与调整是持久数据，不能随临时缓存清理。RAW 原片只读，参数与照片分开存；原生导入使用系统选择器／OS-backed File 授权路径，不能接收网页伪造路径。16 位母版与普通压缩转换应明确区分；解码、颜色及首版限制见 [RAW 工作流](PHOTO-WORKFLOW.md)。

## 房间设计约定

方案和家具统一使用毫米、版本化 JSON；模板、用户保存的模块、场景实例分离。修改实例不能隐式改写模块或其他实例。支持自由旋转，关键角度吸附仅用于鼠标操作，精确输入保留原值；几何检查按旋转后的实际轮廓计算。房间整体旋转可选择是否带动家具。

新建房间方案使用无预设边界的画布。动态长度输入优先于网格，不得悄悄改变用户输入的毫米数；对象吸附需显示类型与位置。Esc 结束连续绘制但保留已落下的开放线段，草稿可保存、继续和撤销；只有主动闭合并通过几何校验后才生成房间。画布缩放、平移及工具栏布局变化不能改变模型尺寸。

二维和未来三维共享 `shared/room.ts`，按需加载渲染器。三维资产以稳定 `modelAssetId` 引用，登记来源、作者、许可证、单位、轴向和尺寸调整策略；不接受方案文件中的任意脚本或可执行入口。当前仅保留三维接口，没有三维模式或第三方模型导入器。资源选择与转换规范见 [房间设计](ROOM-DESIGN.md)。

## 截图接入约定

- ShareX 登记为 `managed` 应用，启动接口返回截图中心页面；保留应用清单的就绪、收藏和最近使用行为。
- 截图、图库、文件操作与快捷键均受登录边界约束。专用组件登录后预热；注销、会话失效或退出时释放，不能接管用户个人 ShareX。
- 快捷键设置先由 Windows 注册候选组合，再保存账号偏好，成功后释放旧组合。注册冲突或保存失败必须回滚；录制期间暂停旧快捷键，取消或失焦时恢复。
- `captureHotkey` 默认 `Ctrl+Alt+S`；`minimizeOnCapture` 默认 `true`。截图按钮、全局快捷键和托盘截图共用此折叠设置，编辑图片不折叠。
- 截图前的窗口退场必须与桌面合成同步，不能用固定延时猜测动画结束。仅临时禁用当前工作箱窗口的过渡动画，使用 DWM cloak 隐去窗口，完成最小化和桌面呈现后才发出截图请求；失败则恢复窗口并终止本次截图。不得修改系统全局动画设置。
- 工具栏始终占位并显示全部操作，无选择时禁用依赖选择的按钮。右键菜单支持鼠标及键盘；重命名使用显式确认的输入框。
- 截图右键菜单统一使用左对齐纯文字，不混用有图标和无图标的菜单项；删除项保留危险色。
- 截图 ID 不随名称变化；原图文件名单独保存。重命名同步文件和数据库，过滤 Windows 非法文件名，失败回滚。原图路径只能由经过鉴权的固定图片 ID 解析，前端不得指定任意本机路径。
- 默认仅本机保存，关闭上传和自动更新。缩略图、原图与元数据属于当前用户；删除先进入回收站。

## 网络测试数据

真实请求产生结果，不展示演示值。测速开始前显示测试时长及流量随网速变化的说明，测试中显示累计用量；只向明确的测速节点发送生成数据。ICMP 丢包率与 TCP 连接失败率分别命名。DNS、TCP、ICMP 的测试口径分别记录。报告包含类型、目标、时间、完成状态、错误和原始样本；记录按账号隔离，最多 50 条，导出由用户选择本地位置。

测速先下载 15 秒、再上传 15 秒，两栏分别展示曲线与最高值。按实际字节每秒采样，曲线平滑显示、数值仅在悬停时读取；平滑不得修改采样或制造额外峰值。精确保存最高采样值，未完成方向的实时值与最终平均值分别显示。上传发送进度不得称作远端接收速率。传输正文只在内存处理，不落盘；正常、停止、失败都释放连接和缓冲，历史只存统计与采样。支持固定节点 ID 切换，失败时不跨节点拼接结果。公网信息只在用户触发检测时查询；将 IP 归属地标为估算，将系统代理配置、实际请求路径和疑似 VPN / TUN 线索分开，不能承诺识别真实住址或排除全部代理。详见 [网络测试](NETWORK-TEST.md)。
